# במה

אפליקציית Flutter לניהול רשימות שירים להופעות, חלוקה לפי סגנון, עריכת שירים והצגת אקורדים.

## יכולות

- רשימות הופעה נפרדות.
- חלוקה לפי סגנונות ומעבר מהיר ביניהם.
- הוספה, עריכה ומחיקה של שירים.
- עורך עם בית, פזמון, מעבר, פתיחה וסיום.
- הדבקת טקסט וזיהוי אקורדים באנגלית כגון C, Am, Dm7 ו-G/B.
- ייבוא TXT ו-PDF טקסטואלי.
- תצוגת במה וטרנספוזיציה.
- שמירה מקומית במכשיר.

## הרצה

flutter pub get
flutter analyze
flutter run

לבניית APK: flutter build apk --release

## קבצים

lib/main.dart, pubspec.yaml, README.md

הערה: PDF סרוק כתמונה דורש OCR; PDF עם שכבת טקסט נתמך.
