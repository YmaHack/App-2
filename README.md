# במה

אפליקציית Flutter/Dart 3 להופעות חיות: מילים ואקורדים, מפת שיר, טרנספוזיציה וגלילה אוטומטית.

## קבצים
- lib/main.dart – כל קוד האפליקציה בקובץ אחד.
- pubspec.yaml – התלויות.
- README.md – הוראות הרצה.

## הרצה

דרישות: Flutter SDK עם Dart 3, Android Studio או VS Code.

    flutter pub get
    flutter analyze
    flutter run

לבניית APK:

    flutter build apk --release

## ייבוא
במסך הספרייה אפשר לייבא TXT או PDF. ב-PDF מתבצע חילוץ עם layoutText ולאחר מכן convert, והטקסט נפתח בעורך לבדיקה לפני השימוש.

PDF סרוק כתמונה אינו נתמך. ב-PDF עם טקסט עברי ייתכן שסדר השורות יהיה הפוך, ולכן יש לבדוק ולתקן בעורך.

## שמירה
כל הנתונים נשמרים מקומית ב-SharedPreferences כ-JSON. בהפעלה הראשונה נוצרים שני תיקיות ושני שירי דוגמה.

מצב במה משתמש ברקע שחור לגמרי, אקורדים צהובים וכפתורים גדולים לקריאה מרחוק.
